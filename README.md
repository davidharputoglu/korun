<a name="français"></a>
## 🇫🇷 Français

**Körün** est un gestionnaire de fichiers multiplateforme moderne construit avec Flutter, doté d'un double panneau de navigation, de deux arborescences rétractables, d'un volet d'aperçu latéral et d'un éditeur d'horodatages.

### Fonctionnalités
- Interface fluide et moderne basée sur Flutter Material 3.
- Double panneau de navigation rapide avec arborescences rétractables indépendantes.
- Modification avancée des dates (création, modification, dernier accès).
- Prise en charge multilingue complète (Français, Anglais, Turc, Arabe avec support RTL).
- Déploiement multi-format : Installeur Windows (.exe), Paquets Linux (.rpm, .deb, .tar.gz) et APK Android.

<a name="english"></a>
## 🇬🇧 English

**Körün** is a modern cross-platform file manager built with Flutter, featuring dual-pane navigation, dual retractable tree views, a side preview panel, and a timestamp editor.

### Features
- Smooth and modern Material 3 user interface powered by Flutter.
- Dual-pane quick navigation with independent retractable side trees.
- Advanced timestamp modification (creation, modification, last access).
- Full multi-language support (French, English, Turkish, Arabic with RTL support).
- Multi-format releases: Windows Setup (.exe), Linux packages (.rpm, .deb, .tar.gz), and Android APK.

## 🇹🇷 Türkçe

**Körün**, Flutter ile geliştirilmiş, çift panelli gezinme, çift açılır-kapanır ağaç görünümü, yan önizleme paneli ve zaman damgası düzenleyiciye sahip modern bir dosya yöneticisidir.

### Özellikler

- Gelişmiş zaman damgası düzenleme (oluşturma, değiştirilme, son erişim).
- Tam çoklu dil desteği (Fransızca, İngilizce, Türkçe, Arapça RTL desteği ile).
- Çoklu format dağıtımı: Windows Kurulum (.exe), Linux paketleri (.rpm, .deb, .tar.gz) ve Android APK.
